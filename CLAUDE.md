# Claude Skills Repository

## Auto-sync Rule

Whenever a skill is added, modified, or deleted in this repository:

1. Stage all changed files: `git add -A`
2. Commit with a descriptive message summarizing what changed (e.g., "Add resume-tailor skill", "Update frontend-design SKILL.md")
3. Push to the `Linux` branch on the remote: `git push origin Linux`

Always ensure you are on the `Linux` branch before committing and pushing.
